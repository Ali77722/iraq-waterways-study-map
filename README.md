# أطلس الرافدين — خريطة العراق التفاعلية

خريطة عربية تفاعلية للمراجعة المدرسية في **الاجتماعيات للصف الثالث المتوسط**، مركّزة على الموارد المائية في العراق.

## المحتويات
- مسارات مبسطة لنهرَي دجلة والفرات وشط العرب.
- طبقات قابلة للإظهار والإخفاء للروافد والفروع والجداول.
- مواقع مختارة للسدود والسدات والبحيرات والأهوار والمدن.
- بحث سريع، نوافذ معلومات، وتتبع تعليمي للمجرى النهري.
- اختبار قصير ذاتي التصحيح.
- واجهة RTL متجاوبة مع الهاتف والكمبيوتر.

## تشغيل الموقع
الموقع ملف HTML ثابت؛ افتح \`index.html\` محليًا أو فعّل GitHub Pages من جذر فرع \`main\`.

## مصادر ودقة البيانات
الشرح والأسماء والقياسات الدراسية أُخذت وصيغت اعتمادًا على كتاب **الاجتماعيات للصف الثالث المتوسط**، وزارة التربية العراقية، طبعة 2025/1447هـ، فقرة الموارد المائية ومجرى دجلة والفرات وشط العرب والأهوار ومشاريع السيطرة والخزن (الصفحات المطبوعة نحو 30–41).

**مهم:** خطوط الأنهار والروافد والفروع في هذا المشروع مخططات تعليمية تقريبية وليست مسحًا هيدرولوجيًا دقيقًا ولا تصلح للملاحة أو تحديد حدود الأراضي. استُخدمت خرائط OpenStreetMap كخلفية مكانية مع إسناد المصدر في واجهة الخريطة. يُحمّل الموقع مكتبة Leaflet وخرائط OpenStreetMap عبر الإنترنت.
