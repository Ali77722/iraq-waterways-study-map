# أطلس الرافدين — خرائط تفاعلية للاجتماعيات

مشروع تعليمي عربي تفاعلي لكتاب الاجتماعيات للصف الثالث المتوسط.

## الصفحات
- [خريطة الموارد المائية](./index.html): دجلة والفرات، الروافد والفروع، الأهوار، السدود والسدات والخزانات.
- [خريطة الفصل الثاني: الخصائص البشرية لجغرافية العراق](./chapter2.html): توزيع السكان، المحاصيل الزراعية، حقول النفط والثروات المعدنية، الصناعات التحويلية، النقل والموانئ، السياحة والآثار.

## التفاعل
- طبقات موضوعية مستقلة يمكن إظهارها وإخفاؤها.
- بحث عربي عن أسماء المواقع.
- نوافذ تشرح المعلم وعلاقته بمحتوى الكتاب.
- اختبار مراجعة ذاتي التصحيح في صفحة الفصل الثاني.
- واجهة RTL مناسبة للهاتف والكمبيوتر.

## المرجع المدرسي
كتاب الاجتماعيات للصف الثالث المتوسط، وزارة التربية العراقية، الطبعة الرابعة، 2025/1447هـ. صفحة الموارد المائية (الصفحات المطبوعة نحو 30–41) وموضوع الخصائص البشرية (الصفحات المطبوعة نحو 45–79).

## ملاحظات الدقة
المواضع والنصوص التعليمية صيغت اعتمادًا على الكتاب. بيانات ترتيب المحاصيل الزراعية التي تحمل سنوات مرجعية هي أرقام يوردها الكتاب (ومنها تقديرات 2018)، وليست إحصاءات معاصرة. خطوط الأنهار وطرق النقل ومناطق السكان تقريبية لأغراض التعلّم، وليست مسحًا رسميًا أو أداة للملاحة.
