# أطلس المياه العراقية — نسخة تعمل دون إنترنت

مشروع دراسي عربي مستقل لموضوع **الموارد المائية** في كتاب الاجتماعيات للصف الثالث المتوسط، الطبعة الرابعة، 2025/1447هـ.

## طريقة التشغيل
افتح ملف \`index.html\` مباشرةً في متصفح حديث. لا يحتاج إلى تثبيت أي شيء أو اتصال بالإنترنت؛ الخريطة SVG ورسومها والشرح والاختبار والبطاقات كلها مضمّنة في الملف، ولا توجد مكتبات أو خطوط أو صور خارجية.

## أقسام الدرس
- خريطة مائية تفاعلية تخطيطية للعراق مع طبقات للأنهار والروافد والفروع والأهوار والسدود والبحيرات والمياه الجوفية.
- شرح تفاعلي من ثماني خطوات.
- تتبّع تعليمي لمحطات دجلة والفرات بالترتيب.
- اختبار من 12 سؤالًا مع التصحيح الفوري ومراجع الصفحات.
- بطاقات حفظ سريعة للتعريفات والنسب والمواقع.

## المرجع المدرسي
كتاب الاجتماعيات للصف الثالث المتوسط، وزارة التربية العراقية، الطبعة الرابعة 2025/1447هـ:
- الموارد المائية ومصادرها: ص 30.
- نهر دجلة وروافده وفروعه: ص 30–32.
- نهر الفرات وفروعه: ص 33–35.
- شط العرب: ص 36.
- الأهوار والمستنقعات: ص 37–38.
- مشاريع السيطرة والخزن: ص 38–41.
- المياه الجوفية: ص 42.
- أسئلة المراجعة: ص 43–44.

## الدقة
النصوص التعليمية والأسماء والنسب والأرقام المرجعية مأخوذة من الكتاب. الخريطة نفسها رسم تعليمي مبسّط أُعدّ لتوضيح العلاقات والمواقع ولا يُستخدم للملاحة أو لتحديد مواقع هندسية دقيقة. الأرقام القديمة تُعرض كما وردت في الطبعة، لا بوصفها إحصاءات آنية.
